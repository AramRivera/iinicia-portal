Bienvenida

Tu ruta para comenzar a construir sitios web.

📌 Configuración del Resumen de Sección en Moodle:

Título: Bienvenida al Curso de HTML Básico
Descripción para mostrar en la página del curso:
¡Hola y bienvenido! Si tu idea es aprender a crear sitios web desde cero, sin conocimientos previos, estás en el lugar indicado. En este curso aprenderás HTML, el lenguaje fundamental con el que se construyen las estructuras de todas las páginas web en Internet. A través de lecciones cortas, amenas y prácticas, dominarás desde las etiquetas más simples hasta la maquetación semántica completa de un sitio web moderno.

📄 Recurso 0.1: Página de Moodle — "Guía de Inicio y Herramientas Necesarias"

¿Qué vamos a aprender?

HTML (HyperText Markup Language o Lenguaje de Marcado de Hipertexto) no es un lenguaje de programación, sino un lenguaje de marcado. Su función principal es crear la estructura de un sitio web: definir dónde van los textos, las imágenes, los formularios, los botones y los menús.

En el desarrollo web profesional, tres lenguajes trabajan siempre de la mano:

  1. HTML: Crea la estructura y el contenido (el esqueleto del sitio).
  2. CSS: Le da estilo visual: colores, formas, tamaños y posiciones (el diseño).
  3. JavaScript: Añade interactividad y dinamismo avanzado.

En este curso nos enfocaremos 100% en dominar las bases sólidas de HTML (incluyendo sus estándares modernos de HTML5).

🛠️ Herramientas que necesitas instalar antes de empezar

Para tomar este curso solo necesitas dos herramientas gratuitas en tu computadora:

  1. Un Navegador Web Moderno: Es el programa que interpretará nuestro código y mostrará la página web.
    • Recomendados: Mozilla Firefox, Google Chrome, Safari u Opera.
    • ⚠️ Importante: Evita utilizar Internet Explorer, ya que es un navegador obsoleto que no interpreta bien los estándares modernos.
  2. Un Editor de Código: Es el programa donde escribiremos nuestras etiquetas HTML. Los editores de código colorean las palabras clave para que sea mucho más fácil leer y encontrar errores.
    • Opciones recomendadas:
      • Sublime Text (Muy rápido y cómodo, cuenta con versión de prueba gratuita ilimitada).
      • Notepad++ (100% gratuito y muy ligero para Windows).
      • Visual Studio Code (El estándar actual gratuito más popular).
      • En última instancia: El Bloc de notas del sistema.
    • 🚫 Qué NO usar nunca: Jamás utilices procesadores de texto como Microsoft Word, ya que agregan código oculto de formato que ensuciará y arruinará tu documento HTML.

MÓDULO 01 / 09

Fundamentos de HTML

Escribe tu primer documento y comprende sus etiquetas.

📌 Resumen del Tema en Moodle:

En este primer módulo comprenderemos las diferencias entre HTML, XHTML y HTML5, aprenderemos la anatomía de una etiqueta y sus atributos, y escribiremos nuestro primer documento web (index.html).

📖 Lección 1: ¿Cómo funciona el código HTML?

1.1 Breve historia: HTML, XHTML y HTML5

Al investigar en internet es común encontrar estos tres términos:

  • HTML: lenguaje de marcado que describe la estructura y el significado del contenido web.
  • XHTML: formulación de HTML con las reglas de sintaxis de XML.
  • HTML5: nombre histórico de una evolución de HTML. El estándar actual se mantiene como HTML Living Standard.

1.2 ¿Qué es una Etiqueta y qué es un Atributo?

Una etiqueta es un fragmento de código encerrado entre signos de menor y mayor que (< >) y representa un elemento en nuestro sitio web (un título, un párrafo, un botón, una imagen).

La gran mayoría de las etiquetas tienen un inicio y un fin (indicado con una barra diagonal /), y en medio llevan su contenido:

<etiqueta>Aquí va el contenido</etiqueta>

Además, las etiquetas pueden tener atributos en su etiqueta de apertura. Un atributo es una propiedad adicional que modifica o identifica a la etiqueta, y suele tener un valor entre comillas; existen también atributos booleanos, como required:

<etiqueta atributo="valor">Contenido</etiqueta>

(Por ejemplo, los atributos más comunes que veremos más adelante son id="identificador" o class="clase", los cuales sirven para conectar HTML con CSS y JavaScript).

Elementos vacíos: Elementos como <br>, <img> e <input> no contienen otros nodos y no llevan etiqueta de cierre. La barra final de <br /> es opcional en HTML y no provoca un autocierre.

<br /> <!-- Etiqueta para dar un salto de línea -->

1.3 Estructura obligatoria de todo documento HTML

Toda página web consta de dos partes fundamentales dentro de la etiqueta raíz <html>:

  1. La Cabecera (<head>): Contiene información técnica para el navegador y para buscadores como Google. Casi nada de lo que se escribe aquí es visible directamente en el lienzo de la página, a excepción de la etiqueta <title>, que cambia el texto de la pestaña del navegador.
  2. El Cuerpo (<body>): Contiene absolutamente todo lo que el usuario verá en pantalla (textos, imágenes, botones, etc.).
<html>
    <head>
        <title>Título de nuestra primera web</title>
    </head>
    <body>
        <!-- Esto es un comentario: solo lo ves tú en el código, no aparece en la web -->
        <h1>Título de nuestro documento</h1>
        <br />
        <h2>Subtítulo de nivel 2</h2>
        <h3>Subtítulo de nivel 3</h3>
        <h4>Subtítulo de nivel 4</h4>
        <h5>Subtítulo de nivel 5</h5>
        <h6>Subtítulo de nivel 6 (el más pequeño)</h6>
    </body>
</html>

1.4 Los Encabezados (<h1> al <h6>) y Comentarios

  • Encabezados (Headers): Existen 6 niveles de titulares, desde el <h1> (el más grande e importante) hasta el <h6> (el más pequeño).
  • Comentarios: Si deseas dejar notas para ti mismo dentro de tu código sin que los visitantes las vean en el navegador, utiliza la sintaxis <!-- Tu nota aquí -->.

1.5 ¿Cómo guardar y visualizar tu página?

  1. Crea una carpeta en tu escritorio llamada mi primer sitio web.
  2. En tu editor de código, ve a Archivo > Guardar como... (File > Save As).
  3. Guárdalo con el nombre index.html (es fundamental poner la extensión .html para que el navegador lo reconozca, y el nombre index es el estándar para la página principal de cualquier sitio).
  4. Haz doble clic sobre index.html para abrirlo en Firefox o Chrome. Cada vez que hagas un cambio en el editor, guarda con Ctrl + S y recarga el navegador con F5.
  5. Tip curioso: Si haces Clic derecho > Ver código fuente de la página en tu navegador (o en sitios como Google o YouTube), podrás ver el código HTML real con el que están hechos.

📝 Tarea 1 (Actividad de Moodle): Mi Primera Página Web

  • Instrucciones para el alumno:
    1. Crea una carpeta en tu computadora para tus prácticas del curso.
    2. Abre tu editor de código y crea un archivo llamado index.html.
    3. Escribe la estructura completa obligatoria (<html>, <head>, <title> y <body>).
    4. En el <title>, coloca tu nombre completo seguido de "- Mi primera web".
    5. Dentro del <body>, escribe un comentario HTML con la fecha de hoy.
    6. Agrega los 6 niveles de encabezados (<h1> al <h6>) con diferentes textos de prueba y separa los dos primeros usando la etiqueta <br />.
    7. Verifica que funcione en tu navegador y sube tu archivo index.html en este espacio.
  • Criterios de calificación (100 pts):
    • Estructura html, head, title y body bien cerrada (40 pts).
    • Uso correcto de h1 a h6 y etiqueta <br /> (40 pts).
    • Inclusión del comentario en el código y extensión .html correcta (20 pts).

MÓDULO 02 / 09

Texto y semántica

Da significado y jerarquía a tus contenidos.

📌 Resumen del Tema en Moodle:

El 80% de la información en internet es texto. En este módulo aprenderemos a maquetar artículos utilizando párrafos, subtítulos, negritas, cursivas y citas, entendiendo cómo Google lee nuestra estructura (Semántica).

📖 Lección 2: Maquetación de Textos y Valor Semántico

2.1 ¿Qué es la Semántica en HTML y por qué le importa a Google?

Maquetar significa construir la estructura de nuestro sitio. Cuando decimos que las etiquetas tienen un valor semántico, significa que le indican al navegador y a los buscadores (como Google) qué significa cada fragmento de texto.

Jerarquía de encabezados: para estas prácticas utiliza un título principal <h1> y organiza las subsecciones con <h2> y <h3>. La jerarquía comunica la estructura; varios <h1> no implican por sí solos una penalización automática de Google.

Nota sobre el tamaño visual: No uses etiquetas HTML solo por el tamaño de la letra que muestran por defecto. Más adelante, con CSS, podrás hacer que un <h2> se vea incluso más grande que un <h1> si así lo deseas. En HTML lo que importa es la jerarquía y estructura.

2.2 Párrafos (<p>) y Separadores (<hr />)

Para los bloques de prosa utiliza párrafos <p> que comuniquen su estructura. Todo bloque de texto normal debe ir encerrado en la etiqueta de párrafo <p>:

<h1>Título de nuestro Artículo</h1>
<h2>Subtítulo del Artículo</h2>

<p>
    Este es nuestro primer párrafo de texto. Al usar la etiqueta p, el navegador 
    agrega automáticamente un espaciado limpio antes y después del párrafo.
</p>

<hr />

<p>
    Este es un segundo párrafo. Si queremos forzar un salto de línea aquí mismo,<br />
    utilizamos la etiqueta br y el texto continúa abajo.
</p>
  • <p>: Define un párrafo semántico con espaciado automático.
  • <br />: Fuerza un salto de línea dentro de un mismo párrafo o entre elementos.
  • <hr />: Etiqueta que se cierra sola y dibuja una línea horizontal separadora entre secciones.

2.3 Etiquetas de Formato y Énfasis en el Texto

Dentro de nuestros párrafos podemos resaltar palabras clave utilizando las siguientes etiquetas:

Etiqueta Ejemplo de Código Función Visual Función Semántica (Para Google)
<b> <b>Texto</b> Negrita por defecto. Llama la atención sin indicar importancia adicional.
<strong> <strong>Texto</strong> Negrita por defecto. Expresa importancia, gravedad o urgencia; no es una garantía de posicionamiento.
<i> <i>Texto</i> Pone la letra en cursiva (itálica). Uso estilístico para términos especiales o extranjerismos.
<span> <span>Texto</span> Ningún cambio visual por sí sola. Sirve como un contenedor neutro para seleccionar palabras específicas y darles color o estilo más adelante con CSS.

2.4 Citas Textuales (<blockquote> y <cite>)

Cuando queremos citar una frase de un libro, autor o artículo externo, utilizamos <blockquote> para la frase (el navegador aplicará un margen o sangría hacia la derecha) y <cite> para indicar el título de la obra citada (no el nombre del autor):

<blockquote>
    "La mayoría de los sitios web se basan en un 80% en texto bien estructurado y el resto es diseño con CSS."
</blockquote>
<cite>Guía de HTML</cite>

📝 Tarea 2 (Actividad de Moodle): Maquetando un Artículo Semántico

  • Instrucciones para el alumno: Crea un archivo llamado articulo.html sobre un tema que te apasione (un videojuego, un libro, ciencia o deportes) que cumpla con los siguientes requisitos:
    1. Un único encabezado <h1> con el título del artículo.
    2. Dos subtítulos <h2> para dividir el tema en dos partes, separados por una línea horizontal <hr />.
    3. Al menos tres párrafos <p>.
    4. Dentro de los párrafos, aplica estratégicamente: dos palabras clave importantes con <strong>, un texto en negrita puramente visual con <b>, una frase en cursiva con <i> y una palabra envuelta en <span>.
    5. Al final del artículo, incluye una cita célebre usando <blockquote> y el título de la obra usando <cite>; escribe el autor como texto normal.
  • Criterios de calificación (100 pts):
    • Uso exclusivo de un solo <h1> y jerarquía correcta con <h2> (25 pts).
    • Uso correcto de <p>, <br /> y <hr /> sin texto suelto (25 pts).
    • Aplicación diferenciada de <strong>, <b>, <i> y <span> (25 pts).
    • Cita estructurada con <blockquote> y <cite> (25 pts).

MÓDULO 03 / 09

Enlaces y rutas

Conecta documentos, recursos y secciones.

📌 Resumen del Tema en Moodle:

La esencia de la web es conectar documentos entre sí. En este módulo aprenderemos a crear hipervínculos externos e internos, abrir pestañas nuevas, configurar enlaces de correo y colocar el icono de nuestra página (Favicon).

📖 Lección 3: Hipervínculos y Rutas en HTML

3.1 La etiqueta <a> y el atributo href

Los enlaces son esos textos (por defecto subrayados en azul) que al hacerles clic redirigen al usuario a otra página o archivo. Se crean con la etiqueta <a> (anchor) y su atributo indispensable href (donde indicamos la URL o dirección de destino):

<a href="https://www.google.com">Ir a Google</a>

3.2 Rutas Absolutas vs. Rutas Relativas

Existen dos formas de indicarle al atributo href hacia dónde debe ir:

  1. Rutas Absolutas (Enlaces externos):
    Se utilizan cuando enviamos al usuario a otro sitio web en internet cuya dirección ya está predefinida.
    • ¡Muy importante! Siempre debes escribir el protocolo http:// o https:// al inicio. Si solo escribes href="www.google.com", el navegador creerá que estás buscando una carpeta llamada www.google.com dentro de tu propia computadora y dará error.
  2. Rutas Relativas (Enlaces internos):
    Se utilizan para enlazar páginas, imágenes o documentos (.html, .jpg, .pdf, .doc, .ppt) que están guardados dentro de nuestra propia carpeta del sitio web, sin escribir http://.
    • Ejemplo: Si tu archivo index.html está en tu carpeta principal, y al lado tienes una carpeta llamada imagenes que adentro contiene el archivo logo.jpg, la ruta relativa para abrirlo es:
    <a href="imagenes/logo.jpg">Ir a la imagen del logotipo</a>

3.3 Abrir en nueva pestaña (target="_blank") y atributo title

Si el usuario hace clic en un enlace externo, por defecto el navegador navegará en la misma pestaña. Para evitar que el visitante abandone nuestro sitio, agregamos el atributo target="_blank", el cual fuerza al navegador a abrir el enlace en una nueva pestaña:

<a target="_blank" rel="noopener noreferrer" href="https://www.google.com" title="Haz clic para buscar en Google">Ir a Google en otra pestaña</a>

(El atributo opcional title muestra un pequeño recuadro informativo cuando el usuario deja el cursor encima del enlace).

3.4 Enlaces de Correo Electrónico (mailto:)

Podemos hacer que al dar clic en un enlace se abra automáticamente el programa de correo del usuario listo para enviarnos un mensaje usando mailto: dentro del href:

<a href="mailto:contacto@misitioweb.com" title="Enviar correo de contacto">Enviar Mail</a>
  • Ventaja: Rápido de escribir en HTML puro.
  • ⚠️ Desventaja importante: Hoy en día no se recomienda usarlo mucho en sitios públicos porque los robots (bots) de internet rastrean el código en busca de mailto: para recolectar tu dirección y enviarte correo basura (spam). Más adelante es mejor usar formularios de contacto.

3.5 La etiqueta <link> y cómo agregar un Favicon

Dentro de la cabecera <head> existen enlaces especiales que no son para darle clic, sino para conectar recursos a nuestro documento utilizando la etiqueta <link />:

<head>
    <title>Mi Sitio Web</title>
    <!-- 1. Enlazar el icono de la pestaña (Favicon) -->
    <link rel="shortcut icon" type="image/x-icon" href="imagenes/favicon.ico" />
    
    <!-- 2. Enlazar una hoja de estilos CSS (lo usaremos en el futuro) -->
    <link rel="stylesheet" href="estilos.css" />
</head>
  • ¿Qué es el Favicon? Es el pequeño icono que aparece en la pestaña del navegador junto al título (como la "G" de Google). Se recomienda que el archivo se llame favicon.ico y esté en formato .ico.
  • Nota sobre el Caché: Si cambias tu archivo favicon.ico por otro y al actualizar no ves cambios, no te preocupes: los navegadores guardan los iconos en su memoria caché. Deberás borrar el caché del navegador para ver el nuevo icono.

MÓDULO 04 / 09

Listas y navegación

Organiza información y construye un menú.

📌 Resumen del Tema en Moodle:

Las listas tienen un doble propósito en el desarrollo web: organizar información para facilitar su lectura y servir como la estructura base con la que se crean todos los menús de navegación de los sitios web.

📖 Lección 4: Creación de Listas y Submenús

4.1 Listas Desordenadas (<ul>)

Las listas desordenadas (Unordered List) se utilizan cuando el orden de los elementos no altera su significado. Muestran viñetas (puntitos) junto a cada ítem.

  • Se abren con la etiqueta <ul>.
  • Cada elemento o renglón dentro de la lista se encierra en una etiqueta <li> (List Item).
<ul>
    <li>Item número 1</li>
    <li>Item número 2</li>
    <li>Item número 3</li>
</ul>

4.2 Listas Ordenadas (<ol>)

Las listas ordenadas (Ordered List) funcionan exactamente igual, pero cambiamos la etiqueta contenedora por <ol>. El navegador numerará automáticamente cada elemento <li> (1, 2, 3, 4...):

<ol>
    <li>Primer paso</li>
    <li>Segundo paso</li>
    <li>Tercer paso</li>
</ol>

4.3 Listas Anidadas (Sublistas)

Podemos meter una lista dentro de otra lista para crear subniveles o submenús con la profundidad que deseemos. Para hacerlo correctamente, la nueva lista <ul> u <ol> se coloca dentro del elemento <li> padre:

<ul>
    <li>Elemento 1</li>
    <li>Elemento 2
        <ul>
            <li>Sub-elemento 2.1</li>
            <li>Sub-elemento 2.2</li>
        </ul>
    </li>
    <li>Elemento 3</li>
</ul>

4.4 ¿Cómo se hacen los Menús de Navegación en la vida real?

Prácticamente todos los menús de navegación profesionales en las páginas web se construyen utilizando una lista desordenada (<ul>) cuyos elementos (<li>) contienen enlaces (<a>). Más adelante, con CSS, se les quitan los puntitos y se acomodan horizontalmente con colores y efectos:

<ul>
    <li><a href="#">Inicio</a></li>
    <li><a href="#">Categorías</a>
        <ul>
            <li><a href="#">Diseño Web</a></li>
            <li><a href="#">Desarrollo</a></li>
        </ul>
    </li>
    <li><a href="#">Contacto</a></li>
</ul>

(Tip: Cuando ponemos un símbolo de gato o almohadilla href="#" en un enlace de prueba, el enlace se activa visualmente pero no nos redirige a ningún otro sitio al darle clic).

📝 Tarea 3 (Actividad de Moodle): Creando Listas y la Estructura de un Menú

  • Instrucciones para el alumno: Crea un archivo llamado listas.html que incluya:
    1. Un subtítulo <h2> que diga "Menú de Navegación del Sitio" seguido de una lista desordenada (<ul>) con 4 enlaces (<a href="#">). El segundo elemento debe tener una sublista anidada con 3 subcategorías (también con enlaces).
    2. Una línea separadora <hr />.
    3. Un subtítulo <h2> que diga "Pasos para crear un sitio web" seguido de una lista ordenada (<ol>) con al menos 5 ítems explicativos.
  • Criterios de calificación (100 pts):
    • Anidación correcta del submenú dentro del <li> correspondiente (40 pts).
    • Uso de etiquetas <a href="#"> dentro de cada <li> del menú (30 pts).
    • Uso correcto de la lista ordenada <ol> (30 pts).

MÓDULO 05 / 09

Imágenes accesibles

Integra imágenes con alternativas de texto.

📌 Resumen del Tema en Moodle:

Una web sin imágenes es aburrida. En este módulo aprenderemos a insertar imágenes en diferentes formatos, controlar su tamaño sin deformarlas y optimizar sus atributos para Google.

📖 Lección 5: La etiqueta <img /> y sus Atributos

5.1 Insertar una imagen con <img /> y src

Para agregar una imagen utilizamos la etiqueta <img />, la cual es un elemento vacío. Su atributo obligatorio es src (source o fuente), donde escribimos la ruta hacia la imagen (soportando formatos como .jpg, .png, .gif, etc.):

<img src="imagenes/logo.jpg" />
  • ¿Ruta Relativa o Ruta Absoluta en imágenes?
    Puedes copiar el link directo de una imagen de Google (ruta absoluta https://...) y pegarlo en el src, pero no es recomendable. Si el dueño de ese otro sitio web borra la imagen o su servidor se cae, tu página se quedará sin imagen. Lo mejor es descargar tus imágenes en una carpeta imagenes/ dentro de tu proyecto y usar siempre rutas relativas.

5.2 Controlar el Tamaño (width y height) sin deformar la imagen

Podemos modificar el tamaño en píxeles usando los atributos width (ancho) y height (alto):

<!-- Opción 1: Poner medidas proporcionales exactas -->
<img src="imagenes/logo.jpg" width="300" height="300" />

<!-- Opción 2 (Recomendada en HTML): Definir SOLO el ancho o SOLO el alto -->
<img src="imagenes/logo.jpg" width="300" />

💡 Truco para no deformar imágenes:
Si una imagen es cuadrada (800x800) y le pones width="300" height="100", la imagen se verá aplastada y fea. Si especificas únicamente el width="300" (y omites el height), el navegador calculará la altura automáticamente de forma proporcional. (Recuerda que en proyectos finales controlaremos los tamaños desde CSS).

5.3 Atributos clave para SEO y Accesibilidad: alt y title

Nunca dejes una etiqueta <img /> solo con el src. Debes acompañarla siempre de:

  1. alt (Texto Alternativo - Indispensable):
    Es una breve descripción de la imagen. Sirve para dos cosas vitales:
    • Si la ruta de la imagen está mal escrita o el usuario tiene mala conexión a internet y la imagen no carga, el navegador mostrará este texto en su lugar.
    • Posicionamiento en Google (SEO): Google no "ve" imágenes como un humano, sino que lee el atributo alt para saber de qué trata la imagen y posicionar tu web en Google Imágenes.
  2. title (Descripción emergente):
    Muestra un recuadro con información adicional cuando el usuario pasa el ratón por encima de la imagen.
<img src="imagenes/logo.jpg" width="300" alt="Logotipo de FalconMasters" title="Logotipo diseñado por Carlos Arturo" />

5.4 Imágenes de Contenido vs. Imágenes de Adorno

En HTML solo debemos colocar con <img /> aquellas imágenes que aportan valor al contenido (fotos de un artículo, logotipos, productos). Las imágenes que son meramente decorativas (como fondos de página, texturas o bordes) no aportan nada a Google y se deben agregar mediante CSS.

Tablas de datos

Representa información con filas y encabezados.

📌 Resumen del Tema en Moodle:

En este módulo aprenderemos a organizar datos estadísticos, horarios o comparativas mediante filas y columnas, aclarando por qué jamás deben usarse las tablas para diseñar la estructura de un sitio web.

📖 Lección 6: Uso Correcto y Creación de Tablas

6.1 La polémica de las Tablas: ¿Cuándo usarlas y cuándo NO?

Hace muchos años, algunas personas cometían el grave error de construir páginas web enteras dentro de una tabla gigante (usando una columna para el menú y otra columna para el contenido). Hoy en día, estructurar un sitio web con tablas es una de las peores prácticas que existen.

  • ❌ Uso Incorrecto: Maquetar el diseño o las columnas de una página web.
  • ✅ Uso Correcto: Tabular datos. Es decir, mostrar horarios, listas de precios, estadísticas deportivas, calificaciones o registros financieros.

6.2 Etiquetas para construir una Tabla (<table>, <tr> y <td>)

Una tabla se construye fila por fila (de arriba hacia abajo) utilizando tres etiquetas:

  1. <table>: Es el contenedor general que indica que ahí inicia y termina una tabla.
  2. <tr> (Table Row): Crea una fila horizontal.
  3. <td> (Table Data): Crea cada columna o celda dentro de esa fila.

Veamos cómo construir una tabla de 3 filas por 3 columnas (3x3):

<table>
    <!-- Fila número 1 -->
    <tr>
        <td>Elemento #1</td>
        <td>Elemento #2</td>
        <td>Elemento #3</td>
    </tr>
    <!-- Fila número 2 -->
    <tr>
        <td>Elemento #4</td>
        <td>Elemento #5</td>
        <td>Elemento #6</td>
    </tr>
    <!-- Fila número 3 -->
    <tr>
        <td>Elemento #7</td>
        <td>Elemento #8</td>
        <td>Elemento #9</td>
    </tr>
</table>

Nota: usa <th scope="col"> para encabezados, <caption> para el título de la tabla y <td> para los datos. Los bordes y espacios se controlan con CSS.

    • Las siguientes tres filas deben contener los datos correspondientes de cada producto.

MÓDULO 07 / 09

Formularios

Recoge información con controles y etiquetas.

📌 Resumen del Tema en Moodle:

Los formularios permiten que el usuario interactúe con nuestro sitio web: iniciar sesión, registrarse, realizar búsquedas o enviarnos mensajes. En este módulo dominaremos todos los controles y campos de entrada de HTML y HTML5.

📖 Lección 7: Creación de Formularios y Tipos de Inputs

7.1 La etiqueta contenedora <form>

Todo formulario comienza y termina con la etiqueta <form>. Tiene dos atributos principales que se utilizan cuando conectamos la web con un lenguaje de programación de servidor (como PHP):

  • action: Indica el archivo que procesará los datos enviados (ej. datos.php).
  • method: Define cómo se enviará la información (POST o GET).
<form action="datos.php" method="POST">
    <!-- Aquí adentro van todos los inputs y botones -->
</form>

7.2 Campos de Texto (<input type="text">) y sus Atributos

La etiqueta <input /> (que se cierra sola) cambia completamente de forma según lo que escribamos en su atributo type. Para una caja de texto normal usamos type="text":

<input type="text" placeholder="Escribe tu nombre" maxlength="20" name="nombre" id="nombre" />

Atributos esenciales de un <input>:

  • placeholder (De HTML5): Muestra un texto guía gris claro dentro de la caja que desaparece automáticamente en cuanto el usuario empieza a escribir. (Mucho más cómodo que el atributo value="Escribe tu nombre", el cual obligaba al usuario a borrar el texto manualmente).
  • maxlength: Limita el número máximo de caracteres que el usuario puede escribir (ej. maxlength="2" solo deja escribir dos letras).
  • size: Cambia el ancho visual de la caja (aunque se recomienda controlar el tamaño con CSS).
  • name: Nombre clave con el que el servidor identificará ese dato.
  • id: Identificador único en el documento HTML, indispensable para vincularlo con su etiqueta <label>.

7.3 La etiqueta <label> y el efecto Focus

Para indicarle al usuario qué debe escribir en un campo, usamos la etiqueta <label> con su atributo for. Si el valor de for coincide exactamente con el id del <input>, al hacer clic sobre las palabras del texto el cursor se activará automáticamente dentro de la caja de texto (focus):

<label for="nombre">Ingrese su nombre:</label>
<input type="text" placeholder="Escribe tu nombre" name="nombre" id="nombre" />

7.4 Catálogo de Controles e Inputs en HTML y HTML5

  1. Contraseña (password) y Correo (email):

    • type="password": Oculta lo que el usuario escribe mostrando puntitos o asteriscos.
    • type="email" (HTML5): Valida automáticamente que el usuario haya escrito un formato de correo válido con @ antes de permitir enviar el formulario.
    <input type="password" placeholder="Contraseña" />
<input type="email" placeholder="Correo electrónico" />

  2. Casillas de Verificación (checkbox) vs. Botones de Opción Única (radio):

    • checkbox: Cuadritos que permiten marcar o desmarcar múltiples opciones a la vez.
    • radio: Círculos donde el usuario solo debe elegir una opción entre varias (por ejemplo, Hombre o Mujer). (Nota técnica: Para que dos botones radio se excluyan entre sí y no dejen marcar ambos al mismo tiempo, ambos deben compartir exactamente el mismo atributo name="genero").
    <!-- Checkbox (selección múltiple) -->
<input type="checkbox" name="terminos" id="terminos" /> Acepto los términos

<!-- Radio buttons (selección única gracias a que comparten name="sexo") -->
<input type="radio" name="sexo" value="hombre" /> Hombre
<input type="radio" name="sexo" value="mujer" /> Mujer

  3. Listas Desplegables (<select> y <option>): Permiten elegir una opción de un menú desplegable (ideal para elegir un país o ciudad):

    <select name="pais" id="pais">
    <option value="mexico">México</option>
    <option value="colombia">Colombia</option>
    <option value="espana">España</option>
</select>

  4. Inputs especiales de HTML5 (color, range, etc.): HTML5 introdujo selectores nativos como un selector de color o una barra deslizante de rango:

    <input type="color" />
<input type="range" />

  5. Botones (button vs. submit):

    • type="button": Crea un botón simple que por sí solo no hace nada (se usa para programarle acciones con JavaScript). Su texto se define con value.
    • type="submit": Es el botón encargado de enviar los datos del formulario al servidor indicado en action.
    <input type="button" value="Botón sin acción" />
<input type="submit" value="Enviar Formulario" />

MÓDULO 08 / 09

Estructura semántica

Construye páginas con regiones claras.

📌 Resumen del Tema en Moodle:

¡Llegamos al corazón de la arquitectura web! En este módulo aprenderemos a armar el esqueleto completo de un sitio web profesional (Encabezado, Menú, Contenido Principal, Barra Lateral y Pie de Página) utilizando las etiquetas semánticas de HTML5.

📖 Lección 8: Creando el Layout de un Sitio Web Completo

8.1 De la era de los <div> al HTML5 Semántico

Un sitio web estándar se divide en grandes bloques:

  1. Header (Encabezado): Arriba, con el logotipo y el menú de navegación.
  2. Contenedor Principal (Wrapper / Main): En el centro, dividido en la columna de Artículos principales a la izquierda y una columna secundaria o Sidebar (Barra lateral) a la derecha.
  3. Footer (Pie de página): Abajo, con los derechos de autor e información final.

¿Para qué sirve la etiqueta <div> hoy en día?
La etiqueta <div> es un contenedor genérico sin ningún valor visual ni semántico. Antes de HTML5, los programadores usaban <div> para absolutamente todo (<div id="header">, <div id="menu">, <div id="footer">).
Hoy en día ya no se hace así. Actualmente, el <div> se reserva únicamente para agrupar elementos gráficos o de diseño que no tienen relevancia semántica para el buscador (por ejemplo, envolver la etiqueta <img /> del logotipo o un video).

8.2 Las Etiquetas Semánticas de Estructura en HTML5

Para que Google entienda perfectamente qué parte de nuestra página es el menú, cuál es el contenido importante y cuál es publicidad secundaria, utilizamos estas etiquetas:

  • <header>: Define el encabezado visible de nuestra página web. (No confundir con <head>, que es invisible).
  • <nav>: Le indica a Google que la lista <ul> que está adentro es el menú de navegación principal del sitio.
  • <section>: Define una sección genérica o agrupador de bloques (por ejemplo, <section class="wrapper"> para encerrar el centro de la página, o <section class="main"> para encerrar la zona de artículos).
  • <article>: representa contenido autónomo que puede distribuirse de forma independiente, como una noticia o publicación. No recibe prioridad automática en un buscador.
  • <aside>: Representa el Sidebar o barra lateral ("hacia un lado / fuera"). Le dice al buscador que ese contenido es secundario (publicidad, enlaces relacionados, biografía corta), útil para el usuario pero no relevante para el tema central de búsqueda.
  • <footer>: Define el pie de página del sitio web (créditos, derechos reservados).

8.3 Código Completo de la Estructura de un Sitio Web (En ~60 líneas)

Observa qué limpio y legible queda un sitio web completo combinando todo lo aprendido:

<html>
<head>
    <title>Estructura Completa de un Sitio Web</title>
</head>
<body>

    <!-- 1. ENCABEZADO DEL SITIO -->
    <header>
        <div>
            <img src="imagenes/logo.jpg" width="70" alt="Logotipo del Sitio" />
        </div>
        <nav>
            <ul>
                <li><a href="#">Inicio</a></li>
                <li><a href="#">Categoría 1</a></li>
                <li><a href="#">Categoría 2</a></li>
            </ul>
        </nav>
    </header>

    <!-- 2. CONTENEDOR CENTRAL (CONTENIDO PRINCIPAL + BARRA LATERAL) -->
    <section class="wrapper">
        
        <!-- Sección de Artículos Principales -->
        <section class="main">
            <article>
                <h2>Título de nuestro Primer Artículo</h2>
                <p>
                    Lorem ipsum dolor sit amet, consectetur adipisicing elit. 
                    Este es el contenido de una publicación autónoma.
                </p>
            </article>

            <article>
                <h2>Título de nuestro Segundo Artículo</h2>
                <p>
                    Podemos duplicar la etiqueta article tantas veces como publicaciones 
                    tengamos en nuestro blog o página web.
                </p>
            </article>
        </section>

        <!-- Barra Lateral Secundaria (Sidebar) -->
        <aside>
            <h3>Sidebar / Contenido Secundario</h3>
            <p>
                Aquí suele ir información secundaria, widgets, publicidad o enlaces 
                complementarios para el usuario.
            </p>
        </aside>

    </section>

    <!-- 3. PIE DE PÁGINA -->
    <footer>
        <p>Carlos Arturo - FalconMasters. Todos los derechos reservados.</p>
    </footer>

</body>
</html>

(Recuerda: En el navegador, esta estructura se verá de arriba hacia abajo en una sola columna blanca. Pero gracias a que tiene esta estructura semántica con sus clases wrapper y main, al conectarle una hoja de estilos CSS se transforma instantáneamente en un sitio con diseño de columnas, colores y tipografías).

Metadatos, CSS y JS

📌 Resumen del Tema en Moodle:

📖 Lección 9: Etiquetas <meta />, <link /> y <script>

9.1 ¿Qué son los Metadatos (<meta />)?

Los metadatos son etiquetas que se escriben exclusivamente dentro de <head> y se cierran por sí solas (<meta />). Sirven para entregar información técnica y de resumen a los navegadores y buscadores. Sus dos atributos principales son name (el tipo de metadato) y content (el valor o información):

  1. meta description (Esencial para Google):
    Es el resumen de qué trata tu sitio web. Puede usarse como resumen en resultados de búsqueda; el buscador también puede seleccionar otro fragmento. No existe una longitud obligatoria para HTML.
    • Orientación para esta práctica: Puedes redactar entre 150 y 170 caracteres (ni muy corto ni un párrafo enorme).
    <meta name="description" content="Aprende diseño y desarrollo web desde cero con tutoriales prácticos de HTML, CSS y JavaScript." />
  2. meta keywords (Palabras clave):
    Aquí se colocan palabras clave separadas por comas sobre la temática de tu sitio.
    • Nota actual: Google ya no toma en cuenta los meta keywords para posicionar (porque antes la gente abusaba de ellos), y hoy se enfoca en la description y en el contenido real de tus <article>. No es necesario incluirlas en un proyecto moderno; se presentan solo como referencia histórica:
    <meta name="keywords" content="diseño, desarrollo, páginas web, html, tutoriales" />

    (Nota adicional recomendada: También es muy común incluir <meta charset="UTF-8" /> para que el navegador reconozca tildes y la letra "ñ" sin problemas).

9.2 Cómo enlazar una Hoja de Estilos CSS (<link />)

Para darle color, diseño y acomodar nuestro HTML sin ensuciar el documento, creamos un archivo aparte (por ejemplo, estilos.css o dentro de una carpeta css/estilos.css) y lo enlazamos dentro del <head> con la etiqueta <link />:

<link rel="stylesheet" type="text/css" href="css/estilos.css" />
  • rel="stylesheet": Indica que estamos vinculando una hoja de estilos en cascada.
  • type="text/css": Atributo opcional (obligatorio en versiones antiguas, opcional en HTML5).
  • href="...": La ruta relativa (o absoluta) hacia nuestro archivo .css. (Si al enlazarlo no ves cambios, verifica que el nombre del archivo y la carpeta estén bien escritos).

9.3 Cómo agregar o importar código JavaScript (<script>)

Para agregar dinamismo con JavaScript utilizamos la etiqueta <script></script> (esta etiqueta sí debe cerrarse siempre con </script>). Existen dos formas de usarla:

  1. Escribir código directamente adentro (No es lo más recomendado para proyectos grandes):
    <script type="text/javascript">
    alert("Hola desde JavaScript");
</script>
  2. Importar un archivo externo .js mediante el atributo src (La mejor práctica para no ensuciar el HTML):
    <script type="text/javascript" src="javascript.js"></script>

1. Cabecera y Metadatos (15 pts) Incluye <title>, favicon, meta description (150-170 caracteres) y enlaces en <head> correctamente (15 pts). Faltan algunos metadatos o la descripción excede/no alcanza la longitud recomendada (8 pts). No incluye <head> o carece por completo de metadatos (0 pts).
2. Estructura Semántica HTML5 (25 pts) Utiliza impecablemente <header>, <nav>, <section>, <article>, <aside> y <footer>, reservando <div> solo para imágenes (25 pts). Mezcla algunas etiquetas semánticas pero abusa de <div> o anida mal el aside/article (12 pts). No usa etiquetas semánticas de HTML5 o estructura el sitio con tablas (0 pts).
3. Textos, Listas y Tablas (20 pts) Respeta el uso de un único <h1> por página, aplica p, strong, blockquote, cite, listas ul/ol y una table de 3x3 bien formada (20 pts). Usa múltiples <h1> por página o presenta errores al cerrar filas <tr> y celdas <td> (10 pts). Deja texto suelto sin etiquetas <p> y no incluye tablas ni listas (0 pts).
4. Enlaces e Imágenes (15 pts) Todas las imágenes y páginas usan rutas relativas funcionales, target="_blank" en links externos y atributos alt, title y width proporcional (15 pts). Las imágenes se deforman por usar width y height desproporcionados o no tienen atributo alt (8 pts). Las rutas están rotas (apuntan al disco duro local C:\...) o no cargan (0 pts).
5. Formulario Interactivo (25 pts) El formulario en contacto.html integra label vinculados con id, text, email, radio agrupados, select y submit (25 pts). El formulario se muestra pero los <label> no hacen focus o los radio permiten selección múltiple por no compartir name (12 pts). No incluye la página contacto.html ni el formulario (0 pts).
